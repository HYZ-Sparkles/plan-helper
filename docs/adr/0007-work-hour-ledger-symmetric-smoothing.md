# 工时账户：超额与未达标对称均分抵扣

每日实际推进与目标的差额，无论正负，都按均分窗口向后续工作日均分：未达标让后续目标上调，超额让后续下调。工作量总量守恒，像一本可以透支也可以预存的工时账户。

考虑过的备选：① 超额不抵扣（多干白赚）——否决：连续热情期后目标依旧原样，容易拖垮后续节奏，与"科学规划、监督"的定位矛盾；② 结转池手动支取——否决：多一层管理负担，违背自动化监督的定位；③ 均分目标日未达标时窗口顺延（跳过没开应用的日子）——否决：淡化监督，欠的债跟着走才是账户的诚实语义，喘息应通过显式调大均分窗口完成。

后果：当日目标可能低于基准工作时间；慢性赤字不设上限，唯一化解方式是用户调大均分窗口（不自动封顶）；±10% 达标容差以调整后的当日目标为基数；非工作日的推进按超额并入账户；**选择层面的超额不抵扣**（大面板里选了 14h 任务不等于完成了 14h），只有实际完成的超额才抵扣；多日差额滚动叠加，均分目标日未达标则递归再均分；调整后目标对用户透明标注。
