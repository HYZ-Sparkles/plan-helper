# UI 视觉基调：现代扁平 + 玻璃拟态，桌宠独立保留

**Status: superseded by [ADR-0004](0004-visual-tone-warm-light.md)** —— 用户走完 prototype 三个变体后反馈"压抑、需要更阳光"，基调反转。

---

（保留作为决策历史）

桌面应用整体走**现代扁平 + 玻璃拟态 + 暗色为主**（控制面板、大/小看板、设置界面）。桌宠的视觉语言**独立保留**（像素 Oreo Cat 或 Live2D Natori），不强行套用 UI 的扁平/玻璃拟态——它是角色，不是组件。

考虑过的备选：让整个应用统一为像素风（与桌宠同语言）。否决理由：控制面板和看板是**信息密集**的（计划列表、任务进度、子目标勾选、工作时间配置），像素风的可读性差，色彩和特效空间也小。强行统一会让"高级 UI 特效"无处施展，反而削弱桌宠作为角色在视觉上的"被高亮"地位。另一备选是全用现代风，让桌宠也变扁平——否决理由同上，桌宠需要强视觉差异。

后果：UI 工程（Vue + TypeScript）与桌宠资源管理（Oreo Cat 帧序列 / Live2D cubism SDK）是**两套独立技术栈**。前者用现代 CSS / Web 动效；后者用对应格式的播放引擎。两者的渲染窗口与交互层也是分开的（桌宠在独立 always-on-top 窗口）。
