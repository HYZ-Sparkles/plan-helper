# 抢占不变式：进行中的计划必然同等级

任何时刻，所有"进行中"的计划优先级必然相同。开始低等级计划时若存在进行中的更高等级计划，「开始」按钮禁用；更高等级计划开始时，所有进行中的低等级计划自动暂停（暂停原因 = 自动抢占）。

考虑过的备选：允许多等级并存、大面板按优先级分组展示。否决理由：让"优先级驱动专注"的抢占机制形同虚设，且大面板、今日总结、自动恢复全都需要"最高等级"特判。原方案"大面板只显示最高优先级等级的计划"在用户手动开启低等级计划时，会让该计划的任务永远无法进入今日分配（死锁）——本 ADR 顺带删除该特判，大面板显示**所有进行中计划**（不变式保证它们必然同等级）。

后果：

- 恢复规则：当不存在进行中的更高等级计划时，恢复等级最高的"自动抢占"组（整组恢复，逐层向下）；用户主动暂停的计划永不自动恢复。
- 用户想开始低等级计划，必须先完成 / 手动暂停当前高等级计划。
- 数据上计划需要记录暂停原因（`自动抢占` / `用户主动`）。
