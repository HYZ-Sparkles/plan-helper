# 桌宠改用 codex 契约形象包，替代 Oreo Cat

**Status: Active**

2026-09-13 grill 决策。桌宠形象从自维护的 Oreo Cat（24 动画、作息语义：睡觉/吃饭/道具箱）整体切换为 [awesome-codex-pet](https://github.com/legeling/awesome-codex-pet) 仓库的 codex 契约形象包——所有形象统一 9 个标准动作 + v2 额外 16 向环视，帧时长由契约硬性规定，**形象只是皮肤**；内置 **9 个形象**（2026-09-14 选定：Kiko 壁虎 / 月薪喵 / 邦德·福杰 / 哆啦A梦 / 咕咚兔王 / Toothless / 阿尼亚 / 小悟空 / 扣扣企鹅——v2×6 + v1×3，可爱动物向含动漫角色，license 全部干净无 Unknown，署名落设置页"关于"），设置页可切换。术语见 `CONTEXT.md` 的 CodexPetContract 段。

## 决策

- **语义翻转**：工作模式从"睡觉安静陪伴"（Sleep Idle）翻转为"陪你伏案"（running 循环）；休息模式常驻 idle。原 README 的"工作模式可可爱爱、安静的"由本 ADR 取代。
- **业务里程碑动作**（完整白名单见 `CONTEXT.md` PetActionPolicy 段）：waiting（大面板打开期间循环）/ review（推进型进度汇报）/ failed（今日总结未达标）/ jumping（今日任务全部完成庆祝）。抢占暂停等其余业务事件不驱动动作。
- **拖动照抄 codex 原版**：拖起 jumping → 140ms 滑窗主方向 running-right/left（反转实时跟切、竖直 jumping、轴向模糊保持当前）→ 松手立即回常驻。
- **启动 = waving → 按初始状态落常驻；退出 = 直接淡出**——codex 契约没有告别动作（"跳进箱子"无继任者），不做告别仪式。
- **窗口尺寸 64×64 → 96×104**：契约单格 192×208 非正方形，÷2 整数缩放保证像素干净（视觉上约大 1.5 倍）。
- **休息随机池 = 跳跃 + 自主小范围移动**（1:1，每 5 分钟 50% 概率触发；移动为 home / away 交替往返——跑出去留下、下次跑回，home 随拖拽重置。2026-09-13 二次 grill 修订，见下方"修订"节）。原版闲时自演池（waving/waiting/review/failed）不采纳——waiting/review 在本方案承载业务语义，进池会稀释信号。
- **Oreo Cat 代码与切帧管线移除**，`resourses/` 原始素材保留存档。"融合"实为"替换"。

## 考虑过的备选

- **保留 Oreo 为可切换的第二行为包**：否决——Oreo 的 24 行作息语义与 codex 的 9 动作任务语义无法共用一套编排，双行为包维护成本不值。
- **维持严格安静原则（业务不驱动动作）**：否决——waiting / review / failed 恰是 codex 动作的本命语义（等批准/检查产出/出错泄气），且触发频率天然极低（failed 一天至多一次）。
- **waiting 绑定"今日未确认"而非"面板打开"**：用户裁决采用后者——"面板开着 = 等你分配"，规则更简单，已确认后重开调整也演 waiting。
- **竖直拖动沿用旧引擎的冻结帧**：否决——保真优先，照抄原版 jumping。
- **休息随机池加跑圈（自主位移）**：否决——原版 running-right/left 仅用于拖拽反馈，自主位移超出原版用法，且用户选择极简池。**（2026-09-13 复议翻转：改采 home/away 交替往返式自主移动，见下方"修订"节。）**

## 后果

- 切帧管线重写：契约是固定 8 列网格（v1 1536×1872 / v2 1536×2288，格 192×208），替代 Oreo 的"非透明列段检测"方案。
- 窗口 64×64 → 96×104：菜单摆位、小看板刚性挂靠、拖拽边界的锚点尺寸随之调整。
- v1 形象无环视行：视线跟随鼠标仅 v2 可用，按 `pet.json` 的 `spriteVersionNumber` 自动降级，不限制选形象。内置 9 个中哆啦A梦 / 阿尼亚 / 小悟空为 v1（无环视），其余 6 个 v2。
- 打包体积：9 份 spritesheet 合计约 19MB（每份 1.7~2.8MB，已逐一验证符合契约尺寸）。
- 授权：资产多为基础 CC BY-NC 4.0（个人使用合规、需署名），选形象时避开 Unknown license；署名落设置页"关于"。
- 气泡文案去"喵"形象无关化（「右键打开菜单」）。
- README 桌宠模块的动作映射整节需重写（README 不可由 agent 修改，由用户更新）。

## 修订（2026-09-13 二次 grill：随机池加入自主移动）

用户复议后，休息随机池从"只跳跃"扩为"跳跃 : 自主移动 = 1:1"。自主移动是对原版用法的延展（原版 running-right/left 仅用于拖拽反馈、原版桌宠从不自主位移），采用 **home / away 交替往返**而非持续漂移：在 home 跑出去（单程 64~128 逻辑像素随机、方向取屏幕余量大侧、目标钳进工作区且距边缘 ≥20px）**留在 away**，下次触发跑回 home；**拖拽即重置 home 并清除 away 态**；away 无足够空间时本次降级为跳跃；移动期间视线跟随挂起。取舍：接受"拖拽与自主移动共用同款动画"的双语义（视觉同构于 Oreo"跑去吃饭"），换随机动作的生气；位置控制权仍归用户（home 概念 + 拖拽重置）。

## 修订（2026-09-14 验收反馈：形象收缩、环视激活半径、渲染平滑插值）

- **内置形象 9 → 7**：Toothless、咕咚 删除（图效果不好）；邦德·福杰保留但**忽略环视**（v2 转向效果不好）——环视能力不再只由 spriteVersion 决定（注册表 `gazeIgnored` 标记，`skinCanGaze` 裁决）。
- **环视改激活半径制**：指针进入桌宠约 240 逻辑像素内才跟视（超出回 idle——安静不注目、靠近才互动）；保留正中死区（指针压在桌宠身上方向无意义）。
- **渲染弃用 `image-rendering: pixelated`**（Oreo 像素风的遗产）：codex 素材为带抗锯齿的绘画风，最近邻在 ÷2 缩放下逐帧抽取不同像素行、轮廓忽隐忽现（用户反馈「动作帧突发变大变小」）；改浏览器平滑插值，窗口维持 96×104。
