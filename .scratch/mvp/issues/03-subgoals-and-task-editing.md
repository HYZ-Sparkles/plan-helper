# 03: 子目标输入与任务编辑

**What to build:** 任务卡勾选"需要子目标"后展开精简输入行，用户能流式录入有序子目标（内容 + 预计耗时，回车自动加行聚焦下一行）；能编辑未完成任务/子目标的字段与顺序、软删除任务；进行中的计划能追加新任务。删除任务永远可点，但必须走"将丢失 X 小时进度"确认弹窗并打字「再删」。

背景：spec 用户故事 5–6、9–11、38；术语 SubGoalAllocation / CreationUI 精简输入行 / TaskDeletion；进度公式见 ADR-0002。

**Blocked by:** 02 创建无子目标计划

**Status:** ready-for-agent

- [ ] 勾选"需要子目标"展开精简输入行：内容（必填单行）+ 预计耗时（必填，默认单位小时），行末 + 按钮与回车都能加行并聚焦内容框
- [ ] 保存校验：勾了子目标的任务至少 1 个子目标（服务层测试覆盖）
- [ ] 子目标顺序 = 填写顺序，不可拖拽；单条可删（确认），后续顺序递进
- [ ] 未完成任务/子目标字段可改、顺序可调，顺序必然排在已完成之后；已完成字段锁定
- [ ] 取消勾选"需要子目标"弹确认（"将删除 X 个子目标"）后清空
- [ ] 删除任务：按钮永远可点 → 确认弹窗显示将丢失的进度 → 打字「再删」→ 软删除进归档（不物理删除）
- [ ] 进行中的计划可追加新任务，新任务排在所有未完成任务之后，依赖与顺序照常编辑
- [ ] 进行中修改预计耗时或增删未完成子目标时，进度按已完成分钟数自动缩放（服务层测试：改耗时前后派生进度一致缩放）
