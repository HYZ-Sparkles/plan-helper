# 04: 依赖编辑

**What to build:** 用户能在任务卡上从**同计划**的其他任务中多选"前置任务"，表达 A→B 的硬依赖；系统能计算依赖闭包、拒绝成环；删除前置任务时依赖自动解除、后继解锁。

背景：spec 用户故事 7、25；ADR-0008（任务顺序是硬依赖边）；术语 TaskDependency / DependencyEditor。

**Blocked by:** 03 子目标输入与任务编辑

**Status:** ready-for-agent

- [ ] 任务卡提供"前置任务"多选选择器，候选仅同计划其他任务；控件收在次要区域/编辑态，不占常驻空间
- [ ] 依赖边仅限同一计划内（服务层拒绝跨计划依赖）
- [ ] 成环（A→B→A，含更长环）被拒绝并提示（服务层测试覆盖环检测）
- [ ] 删除作为前置的任务时依赖自动解除，后继任务解锁（服务层测试）
- [ ] 领域服务提供"任务当前是否可选入今日分配"的依赖判定（前置全部已完成才可选）——供 06 大面板消费，服务层测试覆盖
