# 05: 计划生命周期

**What to build:** 计划状态机沿单向瀑布流转（未开始→进行中；进行中↔已暂停；进行中→已完成（手动确认）；进行中/已暂停→已放弃），终态不可重启。生命周期操作接线到**详情页头部**：开始 / 手动暂停（原因记"用户主动"）、放弃（二级确认打字「再删」）、所有任务完成后亮起「完成计划」按钮、终态计划"复制并新建"。计划列表支持拖拽手动排序。计划管理筛选栏（03 已建）与状态流转联动。

背景：spec 用户故事 12–14、17–22、56–57；ADR-0001（状态机单向瀑布）；术语 PlanStatus / PlanCompletionConfirm / AbortPlan / CopyAsNewPlan / PlanManagementView / PlanOrdering / PauseReason。2026-08-23 grill：操作入口从"控制面板"改到详情页头部。

**Blocked by:** 03 计划详情页与表单紧凑化

**Status:** ready-for-agent

- [ ] 状态机只允许：未开始→进行中；进行中↔已暂停；进行中→已完成（手动确认）；进行中/已暂停→已放弃；非法转换被服务层拒绝（集成测试覆盖全部合法/非法转换）
- [ ] 手动暂停记录 pause_reason = 用户主动；开始/停止按钮在详情页头部（按当前状态显示可得操作）
- [ ] 任务进度到 100% 自动转已完成（TaskStatus，服务层测试）；所有任务已完成时计划**停留进行中**，详情页亮起「完成计划」按钮，用户确认后才转"已完成"（验收可用服务层/种子数据驱动任务到完成态）
- [ ] 放弃计划：一级确认（"将保留 X 个任务 / Y 小时进度作为历史"）+ 打字「再删」→ 已放弃终态，进度进归档可查
- [ ] 复制并新建（仅终态计划、详情页头部按钮）：复制名称/详细内容/优先级/截止日期/任务与子目标，进度与子目标完成状态归零，名称加"- 副本"，新计划直接进入进行中；旧计划保持终态
- [ ] 计划开始后优先级不允许调整（服务层拒绝 + 编辑态 UI 禁用）
- [ ] 终态计划无"重新开始"，只有"复制并新建"；筛选栏各状态数量随流转实时更新
- [ ] 计划列表可拖拽手动排序（拖动半透明 + 3px 主色条、±20px 吸附、他卡让位），手动顺序持久化且优先于默认排序
- [ ] 手动验收：生命周期按钮矩阵（各状态显示哪些操作）、放弃二级确认流、复制并新建归零、列表拖拽排序持久化
