# 05: 计划生命周期

**What to build:** 计划状态机沿单向瀑布流转（未开始→进行中；进行中↔已暂停；进行中→已完成（手动确认）；进行中/已暂停→已放弃），终态不可重启。生命周期操作接线到**详情页头部**：开始 / 手动暂停（原因记"用户主动"）、放弃（二级确认打字「再删」）、所有任务完成后亮起「完成计划」按钮、终态计划"复制并新建"。计划列表支持拖拽手动排序。计划管理筛选栏（03 已建）与状态流转联动。
