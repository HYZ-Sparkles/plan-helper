# 05: 计划生命周期

**What to build:** 用户能开始/手动暂停计划、放弃计划（二级确认打字「再删」）、在所有任务完成后手动确认「完成计划」、对终态计划"复制并新建"；计划管理 4-tab 归档视图完整可用。计划状态沿单向瀑布流转，终态不可重启。

背景：spec 用户故事 12–14、20–22、56–57；ADR-0001（状态机单向瀑布）；术语 PlanStatus / PlanCompletionConfirm / AbortPlan / CopyAsNewPlan / PlanArchiveView / PlanOrdering / PauseReason。

**Blocked by:** 03 子目标输入与任务编辑

**Status:** ready-for-agent

- [ ] 状态机只允许：未开始→进行中；进行中↔已暂停；进行中→已完成（手动确认）；进行中/已暂停→已放弃；非法转换被服务层拒绝（集成测试覆盖全部合法/非法转换）
- [ ] 手动暂停记录 pause_reason = 用户主动；开始/停止在控制面板操作
- [ ] 任务进度到 100% 自动转已完成（TaskStatus，服务层测试）；所有任务已完成时计划**停留进行中**，控制面板亮起「完成计划」按钮，用户确认后才转"已完成"（验收可用服务层/种子数据驱动任务到完成态）
- [ ] 放弃计划：一级确认（"将保留 X 个任务 / Y 小时进度作为历史"）+ 打字「再删」→ 已放弃终态，进度进归档可查
- [ ] 复制并新建（仅终态 tab 内按钮）：复制名称/详细内容/优先级/截止日期/任务与子目标，进度与子目标完成状态归零，名称加"- 副本"，新计划直接进入进行中；旧计划保持终态
- [ ] 计划开始后优先级不允许调整（服务层拒绝 + UI 禁用）
- [ ] 4-tab（进行中/已暂停/已完成/已放弃）+ 数量徽章完整；默认 tab"进行中"；终态计划无"重新开始"，只有"复制并新建"
- [ ] 计划列表可拖拽手动排序（拖动半透明 + 3px 主色条、±20px 吸附、他卡让位），手动顺序持久化且优先于默认排序
