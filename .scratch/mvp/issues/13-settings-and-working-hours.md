# 13: 工作时间与设置

**What to build:** 控制面板「设置」页完整可用：每日工作时间、每周工作日、日内多段时间窗口、日期例外（双向覆盖）、均分窗口。工作时间类改动自下一个工作日生效；均分窗口立即生效。工作窗口开始触发大面板、最晚窗口结束触发今日总结；跨午夜窗口归属开始日；非工作日不自动弹大面板（手动加班可分配，2026-08-29 用户决策、06 已实现加班态）、推进按超额入账。

背景：spec 用户故事 47–49、23（窗口触发）；术语 WorkingHours / DateOverride / SettingsEffectiveTime / AutoOpenMainBoard / DailySummaryTrigger；结算联动见 ADR-0007。

**Blocked by:** 10 工时账户结算, 11 今日总结

**Status:** ready-for-agent

- [ ] 设置页五项：每日工作时间、每周工作日（周循环多选）、日内时间窗口（可增删多段，如 10:00–11:30, 20:00–22:00）、日期例外（按日期标记"这天不工作"/"这天工作"，双向覆盖周循环）、均分窗口（工作日数）
- [ ] 生效时机：工作时间/工作日/时间窗口改动自**下一个工作日**生效（当日目标、达标判定、总结不受影响）；均分窗口改动**立即生效**（服务层测试用时钟注入验证两种生效）
- [ ] "今日是否工作"判定 = 周循环 + 日期例外合并；非工作日：大面板不**自动**弹（手动切入工作模式 = 主动加班可开面板分配，2026-08-29 用户决策、06 已实现加班态）、当日不计入均分窗口
- [ ] 非工作日的推进照常记任务进度，工作量按**超额**并入工时账户（结算回归测试）
- [ ] 工作窗口**开始时**触发 AutoOpenMainBoard（条件：工作模式 + 今日未分配）；启动序列完成后接入 06 的启动检测路径
- [ ] 最晚工作窗口结束触发 11 的今日总结（替代种子数据验收路径）；当天没开应用次日弹"昨日总结"
- [ ] 跨午夜窗口（如 20:00–01:00）内的汇报与总结归属**窗口开始日**（服务层测试跨午夜场景）
- [ ] 设置持久化，重启保持；01 落库的默认值在设置页可见可改
