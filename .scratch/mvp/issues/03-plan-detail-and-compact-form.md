# 03: 计划详情页与表单紧凑化

**What to build:** 计划管理页结构重组：状态筛选栏（全部/未开始/进行中/已暂停/已完成/已放弃 + 数量，默认"全部"）替代 4-tab；点击计划卡进入**计划详情页**（头部：计划字段+优先级标签+状态徽章+生命周期按钮占位（05 接线）+「编辑」；正文：任务列表）。「编辑」把正文切成编辑态——**复用创建表单组件（创建/编辑双模式）**；创建表单同时紧凑化：任务卡默认收起为一行摘要（拖拽手柄 + 名称 + 预计耗时/子目标标记），点行展开完整字段，长字段只在展开态。任务拖拽排序（创建与编辑同一交互）、未完成任务字段编辑、进行中追加任务、软删除任务。

背景：spec 用户故事 2、9–11、56、56a、56b；术语 PlanManagementView / PlanDetail / CreationUI（双模式+任务卡形态）；2026-08-23 grill 决策（用户否决 4-tab 与主从布局，详情走独立整页——计划少而任务/子目标多）。

**Blocked by:** 02 创建无子目标计划

**Status:** implemented（待手动验收）

- [x] 表单组件双模式：创建页与详情页编辑态共用同一 CreationUI 组件，字段与校验一致；编辑保存走服务层更新（整计划覆盖，服务层测试覆盖字段变更落库）

### 实现说明

- Rust：`NewPlan/NewTask` 改名 `PlanDraft/TaskDraft`（任务草稿带可选 id，创建/编辑共用）；`PlanService::get`（详情）/ `update`（整计划编辑）/ `delete_task`（软删除归档）+ 8 个新接缝测试。update 不变量：已开始锁优先级、已完成任务内容锁定（TaskLocked）、任务集一致（TaskSetMismatch，删除显式走 delete_task）、未完成按提交序在前 + 已完成按库内序沉底。
- 前端：`CreationForm.vue`（双模式单页表单，紧凑任务卡 + HTML5 拖拽 + 删除打字确认）、`PlanDetailPage.vue`（`/control-panel/plans/:id`）、`TypeConfirmDialog.vue`（打字确认弹窗，05 放弃计划复用）、PlansPage 筛选栏返工；全局类 `.ghost-btn` 与 token `--overlay-dim` 入 tokens.css。
- 范围备注：**优先级锁定（服务层拒绝 + 编辑态 UI 禁用）已随本工单落地**——编辑态是 03 引入的，不锁即违反不变式；工单 05 的对应项（checkbox 6）届时直接勾掉即可。
