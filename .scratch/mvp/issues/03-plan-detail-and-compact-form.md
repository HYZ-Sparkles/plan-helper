# 03: 计划详情页与表单紧凑化

**What to build:** 计划管理页结构重组：状态筛选栏（全部/未开始/进行中/已暂停/已完成/已放弃 + 数量，默认"全部"）替代 4-tab；点击计划卡进入**计划详情页**（头部：计划字段+优先级标签+状态徽章+生命周期按钮占位（05 接线）+「编辑」；正文：任务列表）。「编辑」把正文切成编辑态——**复用创建表单组件（创建/编辑双模式）**；创建表单同时紧凑化：任务卡默认收起为一行摘要（拖拽手柄 + 名称 + 预计耗时/子目标标记），点行展开完整字段，长字段只在展开态。任务拖拽排序（创建与编辑同一交互）、未完成任务字段编辑、进行中追加任务、软删除任务。

背景：spec 用户故事 2、9–11、56、56a、56b；术语 PlanManagementView / PlanDetail / CreationUI（双模式+任务卡形态）；2026-08-23 grill 决策（用户否决 4-tab 与主从布局，详情走独立整页——计划少而任务/子目标多）。

**Blocked by:** 02 创建无子目标计划

**Status:** ready-for-agent

- [ ] PlansPage 返工：筛选栏（六项各带数量徽章，默认"全部"）替代 4-tab；列表仍按 PlanOrdering 排序；点击卡片进入 `/plans/:id`
- [ ] 详情页：头部（名称+优先级标签+状态徽章+生命周期按钮占位（禁用，05 接线）+「编辑」按钮）、正文任务列表（名+耗时+状态），返回回列表
- [ ] 表单组件双模式：创建页与详情页编辑态共用同一 CreationUI 组件，字段与校验一致；编辑保存走服务层更新（整计划覆盖或差异更新，服务层测试覆盖字段变更落库）
- [ ] 创建表单紧凑化：任务卡默认收起为一行摘要（⠿ 拖拽手柄 + 名称 + 预计耗时/子目标标记），点击展开完整字段（名称/简述/详细内容/子目标开关）；简述、详细内容等长字段只在展开态出现
- [ ] 任务拖拽调整顺序：创建表单与编辑态同一交互；服务层按提交顺序落 position（测试：顺序持久化、重排后已完成任务必然排在未完成之后——已完成锁定不可拖）
- [ ] 未完成任务字段可改；已完成任务字段锁定（服务层拒绝 + UI 禁用）
- [ ] 进行中的计划可追加新任务，新任务排在所有未完成任务之后
- [ ] 删除任务：按钮永远可点 → 确认弹窗显示将丢失的进度 → 打字「再删」→ 软删除进归档（不物理删除）
- [ ] 手动验收：筛选栏切换与数量、卡片点击进详情、编辑态保存生效、拖拽排序手感（矮行）、紧凑形态下 10 任务一屏可见
