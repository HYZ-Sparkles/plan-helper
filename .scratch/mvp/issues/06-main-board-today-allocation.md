# 06: 大面板今日分配

**What to build:** 用户处于工作模式且今日未分配任务时，大面板自动弹出：按计划分组展示所有进行中计划的可选任务，用户勾选并实时看到累计预计耗时对照目标，点底部「确认」完成当日分配；之后可从控制面板重开调整。前置未完成的任务置灰不可选。

背景：spec 用户故事 23–29；术语 MainBoardTodayAllocation / TodayLoadCommitment / AutoOpenMainBoard / TaskDependency；硬约束语义见 CONTEXT（推进硬性、完成柔性、选择层面超额不抵扣）。

**Blocked by:** 04 子目标与依赖, 05 计划生命周期

**Status:** ready-for-agent

- [ ] 自动打开：进入工作模式且今日未分配时弹出（含启动后的检测——启动序列完成后的检测在 08 就绪后接入；工作窗口开始时的触发在 13 就绪后接入）
- [ ] 不触发：今日已分配 / 休息模式 / 今日不在工作日（默认周循环 + 13 前无日期例外）
- [ ] 列表 = 所有 PlanStatus=进行中的计划（此时抢占机制未实现，天然满足"必然同等级"），按 Priority 降序、按计划分组，section header = 计划名 + Phosphor 图标
- [ ] 前置任务未完成的任务置灰、显示"等待：任务A"、不可勾选（消费 04 的依赖判定）
- [ ] 勾选实时累计；底部状态条固定"今日累计 X.X 小时 / 当日实际目标 Y 小时"（目标暂用基准工作时间，10 就绪后升级为含结转的调整后目标并加标注）
- [ ] 累计 < 目标：黄色差额软提示；≥ 目标：无提示；超出不警告、不阻止提交（柔性边界）
- [ ] 「确认」按钮在底部中间，点击持久化当日分配（日期 + 选中任务集）并关闭
- [ ] 控制面板"打开大面板"可重开重选，覆盖旧分配；已推进的进度保留（从 ProgressLog 来，与选择无关）
- [ ] 服务层测试：当日分配的存取、覆盖重选、可选任务集的依赖过滤
