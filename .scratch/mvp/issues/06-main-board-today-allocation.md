# 06: 大面板今日分配

**What to build:** 用户处于工作模式且今日未分配任务时，大面板自动弹出：按计划分组展示所有进行中计划的可选任务，用户勾选并实时看到累计预计耗时对照目标，点底部「确认」完成当日分配；之后可从控制面板重开调整。前置未完成的任务置灰不可选。

背景：spec 用户故事 23–29；术语 MainBoardTodayAllocation / TodayLoadCommitment / AutoOpenMainBoard / TaskDependency；硬约束语义见 CONTEXT（推进硬性、完成柔性、选择层面超额不抵扣）。

**2026-08-29 验收修订（用户决策）：手动切入工作模式 = 主动加班**

- 反馈：休息日从休息模式切到工作模式、今日未分配时，应弹大面板选任务（用户原话"相当于自己选择加班"）。原"非工作日不弹 + 休息日态 UI（分配不加载、隐藏列表）"被取代——休息日空态移除，非工作日打开大面板即**加班态**：可勾选提交，状态条只看累计（无目标/进度条/差额提示），右栏注明"休息日加班 · 推进按超额并入工时账户"，头部提示同步换文案。
- `should_auto_open` 增参 `manual`：自动触发（启动序列后检测 / 13 的工作窗口开始）仍限工作日；手动切入旁路工作日条件（工作模式 + 未分配即弹）。seam 测试补 `should_auto_open_manual_switch_bypasses_workday`（休息日手动 true / 休息模式 false / 已分配 false / 自动 false）。
