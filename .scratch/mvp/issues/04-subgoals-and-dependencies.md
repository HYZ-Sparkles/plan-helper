# 04: 子目标与依赖

**What to build:** 任务卡展开态的两个深化内容：勾选"需要子目标"展开**精简输入行**（内容 + 预计耗时，回车自动加行聚焦），用户能流式录入有序子目标；**前置任务**多选选择器（创建表单与详情编辑态都提供），表达 A→B 硬依赖。领域侧提供依赖服务：仅同计划、拒绝成环、删除前置自动解除、以及供大面板消费的"任务当前是否可选入今日分配"判定。

背景：spec 用户故事 5–7、25、38；术语 SubGoalAllocation / CreationUI 精简输入行 / DependencyEditor / TaskDependency；进度公式见 ADR-0002、依赖见 ADR-0008。2026-08-23 grill：前置任务选择器落点 = 创建+编辑展开态。

**Blocked by:** 03 计划详情页与表单紧凑化

**Status:** ready-for-agent

- [ ] 勾选"需要子目标"展开精简输入行：内容（必填单行）+ 预计耗时（必填，默认单位小时），行末 + 按钮与回车都能加行并聚焦内容框
- [ ] 保存校验：勾了子目标的任务至少 1 个子目标（服务层测试保持绿）
- [ ] 子目标顺序 = 填写顺序，不可拖拽；单条可删（确认），后续顺序递进
- [ ] 取消勾选"需要子目标"弹确认（"将删除 X 个子目标"）后清空
- [ ] 未完成子目标字段可改；已完成锁定；顺序必然排在已完成之后
- [ ] 前置任务多选：任务卡展开态次要区域提供（创建表单与详情编辑态同一控件），候选仅同计划其他任务
- [ ] 依赖边仅限同一计划内（服务层拒绝跨计划依赖）
- [ ] 成环（A→B→A，含更长环）被拒绝并提示（服务层测试覆盖环检测）
- [ ] 删除作为前置的任务时依赖自动解除，后继任务解锁（服务层测试）
- [ ] 领域服务提供"任务当前是否可选入今日分配"的依赖判定（前置全部已完成才可选）——供 06 大面板消费，服务层测试覆盖
- [ ] 修改预计耗时或增删未完成子目标时，进度按已完成分钟数自动缩放（服务层测试：改耗时前后派生进度一致缩放；ProgressLog 于 07 落地后此为派生公式验证）
