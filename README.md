# Plan Helper(任务帮手)

## 项目概述
本项目制作了一个桌面任务伙伴：可爱的桌宠帮助你对计划进行科学的规划和拆解，并且鼓励和监督你完成自己设下的目标。

- 给出一周/一月/一年的计划后,系统自动拆解并排程到每日。任务规划引擎:计划 → 任务 → 子目标,自动生成每日清单。
- 工作/休息模式自动切换，支持自己定义每天的工作时间或者手动点击桌宠开启工作模式
- 工作模式下，桌宠的看板可点击切换：
  - 展示内容:**极简三件套**——当前子目标 + 今日完成数 + 工作时间结束倒计时
  - 交互:子目标默认折叠 1 行;点击左侧按钮看完整清单;点击子目标可进行汇报：完成/进行中(XX%)/卡住/放弃
  - 可拖动到屏幕任意位置
  - 工作时间未汇报则记录为未完成，可以手动开启工作模式进行“加班”。在第二天如果依旧没有完成就会动态调整未完成的工作量。
- 如果不是工作时间下手动开启工作模式：当天任务未完成，显示加班；当天任务已完成，显示超前。拥有特殊的鼓励机制。
- Tauri 桌面应用(Windows 优先,代码层面预留跨平台)
- Live2D 桌宠(透明窗口、常驻桌面)
- 三类鼓励触发:定时(A)/任务节点(C)/进度对比(E)
- 本地数据存储(SQLite)
- LLM 云端 API 集成(DeepSeek + MiniMax,OpenAI 兼容协议)

## 开发
- 技术栈:Tauri 2 + Vue 3 + TypeScript + SQLite

```bash
npm install
npm run tauri dev
```

## 目录结构

- `src/` — Vue 3 前端
- `src-tauri/` — Rust 后端(数据层、排程引擎、LLM 集成)
