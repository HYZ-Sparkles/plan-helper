# Plan Helper(任务帮手)

## 项目概述
本项目制作了一个桌面任务伙伴：可爱的桌宠帮助你对计划进行科学的规划和拆解，并且鼓励和监督你完成自己设下的目标。

## 开发
- 桌面框架:**Tauri**(Rust 后端 + Web 前端)
- 前端框架:**Vue 3 + TypeScript**
- 本地存储:SQLite(rusqlite)
- LLM 客户端:`reqwest` 调 OpenAI 兼容 API

```bash
npm install
npm run tauri dev
```

## 目录结构

- `src/` — Vue 3 前端
- `src-tauri/` — Rust 后端

## 功能模块
项目分为两个模块：计划模块，负责设计和编写计划，开启计划之后每天在桌面上显示看板，用户自主汇报完成进度；桌宠模块：负责当显示看板的伴侣，提供鼓励和监督作用。

项目含有两个模式，休息模式和工作模式。工作模式下桌宠下面挂着小看板，用户可自行查看需要完成的任务，桌宠只需要可可爱爱、安静的；休息模式下用户点击触发桌宠的动作。
点击桌宠可以选择进入控制面板或者在工作模式和休息模式下转换。

桌宠(连同看板)可拖动到屏幕任意位置。桌宠的部分动作可移动，需要结合在桌面上的位置选择合适的移动方向。

### 计划模块

#### 计划定义和构成
计划->任务->子目标

计划就是 "备考英语6级" 这样的具体的大目标，计划的完成会先模块化为一个个任务，例如 "背单词30分钟"、"完成英语真题"。
状态：未开始/进行中/已暂停/已完成/已放弃。
已暂停是防止计划会继续但是目前需要完成更高优先级的计划；已完成和已放弃是为了方便整理和记录。

任务就是计划完成的步骤，计划被模块化为一个个具体的任务。
任务都是一次性的任务(例如 "完成前端代码"，注意"背单词"这种周期性任务可以汇总为"背完所有6级词汇")。
任务之间可以有顺序也可以没有，因此用户自定义完成的顺序：例如任务A、B，用户可以设置 A->B 的完成顺序，也可以设置 A B 的完成顺序，此时用户可以选择一天同时推进A和B。

子目标是任务最终细化的结果，如果任务简单可以不分配子目标。子目标有序，完成任务就是按照顺序完成这些子目标。

计划的最终落实是用准确的指标的，因此任务内容或者子目标内容需要具体。

任务和子目标的状态能够正常支持功能的实现即可，但是**子目标是二态的汇报模式**(未完成/已完成)

#### 计划创建流程
创建计划->创建计划的任务->创建任务具体完成的子目标(可选)

创建计划：输入计划名称，计划简述(默认和计划名称相同)，可以选择输入计划详细内容(详细的计划内容，说明计划需要完成的步骤，自己的想法等等信息)，选择计划的优先级(高中低)。
计划可以选择设置截止时间，但是是为了前端给我看的，不参与任务的分配。
计划的详细内容一是给自己之后模块化任务，细化子目标做准备，二是使用LLM帮助规划计划的完成。

创建计划的任务：添加任务，需要填写任务名称，任务简述(默认和任务名称相同)，可以选择输入任务详细内容。必须要填写任务完成是否需要分配子目标：如果不需要子目标那么必须填写预计耗时，否则直接去填写子目标，预计耗时就是子目标所需完整时间。

创建任务具体完成的子目标：如果任务太简单这一步是不需要的。需要按照次序填写任务完成的详细的子目标的内容，填写子目标预计耗时(小时为单位)

任务和子目标的后期增删改：已完成的不允许修改，未完成的可以修改和自由调整顺序，顺序必然在未完成的之后。
删除任务：二次确认模式
计划如果已经开始那么优先级不允许调整。
因此在制定计划时必须认真。

#### 计划实施说明
在控制面板中选择计划是否开始，突出目前最高的优先级的计划，但是用户依旧自主选择开始哪些计划或者停止哪些计划。

每天第一次进入工作时间时，在大看板进行今日任务分配。
一旦存在更高的优先级的计划开始，大看板中的今日任务分配将只出现高优先级计划，如果低优先级计划进行中，则保存进度并且停止计划。直到高优先级计划完成之后自动恢复之前停止的计划。
如果多个同优先级计划开始，看板会显示各个计划目前完成到的**所有可以并行完成**的任务，我自行选择今日**推进**(注意不是必须完成)哪些任务。
选择的任务的预计耗时总和必须大于等于今日工作时间来保证工作量。

任务的进度汇报：如果有子目标直接汇报子目标，没有子目标使用进度百分比来汇报。任务进度对应的时间使用完成子目标的预计时间相加得到，没有子目标使用百分比直接乘以任务需要时间。
每天的预计工作量按照工作时间来估计，推荐工作时间必须完成对应时间的任务。例如每天5小时的工作时间，那么就可以完成5小时的任务的进度。
工作量超标或者未达标的处理：用户可在控制面板的设置中调节均分时间。均分窗口以工作日为单位，且超额对称抵扣、未达标递归均分，非工作日可用日期例外排除

工作时间结束后生成今日总结。从大面板上说明推进了哪些计划，可以看详细是推进了那个任务，完成了多少子目标。今日工作量是否达标。以及之后工作量均分后的结果。
如果有更高优先级的计划没开始今日总结中需要提示出来。
触发时间：工作时间结束的时候弹出。

### 桌宠模块
资源包存放在 "./resourses/awesome-codex-pet" 目录下，现采用 codex 桌宠融合。

种类：
- Kiko--untko
- salary-cat--Zuochunjie
- bond-forger--legeling
- doraemon--xueshi
- gudong--rank
- toothless--legeling
- anya--chenxin-dlut
- kid-goku--julianhuang
- koukou-penguin--hoody

用户动作对应桌宠动作(codex)
- 启动应用：waving
- 休息模式
  - 常驻：idel
  - 每5min概率性(50%)触发随机动作：
    - 跳跃：jumping
    - 自行移动：在桌面上小范围移动 running-right/running-left，一次移动到其他位置之后，下一次移动回来原位置
  - v2版本 跟着鼠标环视16方向
- 工作模式：running
  - 小面板完成一个子目标或者推进了任务进度：review
- 鼠标拖动：running-right/running-left，对应不同方向的拖动
- 大面板选择今日任务：waiting
- 今日总结：
  - 任务没有达标 -> failed
  - 全部任务完成 -> jumping

在用户产生动作时，桌宠的动作需要先播放完才执行新的动作放置割裂感。
